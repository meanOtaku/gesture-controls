# Evidence coverage and gaps

This document prevents a figure-ready package being mistaken for completed prospective research.

## What is supported now

- **System and hardware positioning:** original diagrams based on the implemented pipeline and the μDPad hardware description. No comparative device-performance results.
- **Annotations and raw signals:** an exact recorded CSV-row excerpt with original/effective labels and unmodified timestamp cells. Display-only PPG scaling is documented. No model curve is inferred from those raw traces.
- **Historical manuscript evidence:** exact snapshot copies of the old audit, recorded score/timing arrays and day-transfer table. Figures reproduce stored evidence, not newly trained historical models.
- **Motion-history remedy:** the original documented synthetic-splice summary. Only the five six-second-burst conditions with exact reported counts are plotted; range-only rows are not turned into invented point-by-point curves.
- **CNNv2 benchmark:** archived threshold sweeps and selected operating points. Two training-OOF budget selections are recomputed; test data is not used to pick a new best cutoff. This does not erase earlier model exploration on the same cohort.
- **Multiclass decisions and events:** original per-recording probability/label/timestamp vectors, exact trainer modules and three checkpoints are bundled. Classification metrics, validation threshold selection and context matrices are independently recomputed. Event accounting is re-executed against the original raw labels using the frozen trainer and checked against the saved results.
- **Later paired binary detectors:** only their archived rounded Markdown summary was located. Corresponding complete run files for its 95/120 and 96/127 claims were not recovered. Other `final-pinch_in` / `final-pinch_out` files have different event denominators and are not valid replacements.
- **Current recording inventory:** a separate read-only audit of 60 exported folders and 45 exact stream pairs. This is not the older 37/28 audit and not a declaration of 45 independent days or participants.

## What remains to collect or recover

| Paper-improvement priority | Missing input / acceptance criterion | Asset status |
| --- | --- | --- |
| Complete interaction | Repeated select–grab–adjust–release tasks; completion/errors, cancellation and sensing-to-OS timestamps | Policy diagram only; no fabricated task-success graph |
| Matched modality ablation | Same source groups, target and selection budget for IMU-only, PPG-only and fusion | No modality-superiority plot; existing unrelated studies are not a matched substitute |
| Physical post-motion recovery | Predeclared real movements and pinches at measured delays | Synthetic summary figure only; physical trial absent |
| Haptic self-triggering | Original actuator log or new matched haptics-on/off recordings, including release during feedback | No time-aligned haptic-effect graph; context saying buzzes occurred is insufficient |
| Prospective generalisation | Method frozen before new days/refits/users; separate calibration allowance | Proposed protocol only; no population CI or “unseen participant” accuracy |
| Joint versus separate recognizers | Matched target definitions and tuning/compute budgets | Delayed-state experiment cannot establish superiority over binary onset models |
| Hold duration | Independent physical onset/offset reference and duration/transition error | State confusion/hold-entry recall only |
| Headset / hand occlusion | Actual camera-only, watch-only and combined trials | Literature positioning and proposed study only |
| Runtime / battery / faults | Actual hardware measurements, unavailable intervals and clock uncertainty | No all-day reliability, power or physical safety chart |
| Paired detector reproducibility | Original full runs, model identities, per-recording logs and exact eligible exposure for the documented summary | Figure marked documented summary, not independent replay |

## Model/protocol boundaries that must survive editing

1. Old 50 Hz input construction is not current 100 Hz input construction.
2. The inference-grid rate is not the native rate of every sensor.
3. A 300–900 ms historical match window and a later 100–900 ms CNN window do not give interchangeable recall.
4. Multiclass targets are annotated states at decision time minus 500 ms; they are not binary onset targets.
5. Peak-window synthetic-splice detection is not continuous event recall.
6. Each class/model has its own negative-time denominator. Rounded FAR in a prose table is not an exact recovered event count.
7. A software seal cannot retroactively make previously examined recordings untouched.
8. Exact stream hashes do not find all partial overlap or repeated-session dependence.
9. A custom-hardware distinction against μDPad is not proof of first commercial-watch PPG gesture sensing.
10. A verified model file and a reproduced replay do not establish safe or successful everyday actuation.

## What was deliberately not done

No new training, threshold tuning on test labels, camera/watch capture, participant study, actuator test, Joplin mutation or manuscript-source rewrite was performed. No synthetic participant outcomes or plausible-looking replacement prediction arrays were used. Full retraining instructions are separate from—and weaker than—the directly exercised saved-vector/frozen-replay reproduction path.
