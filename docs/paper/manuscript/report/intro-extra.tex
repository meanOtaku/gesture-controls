\section{Objectives}

The project set out to:
\begin{enumerate}
\item build a complete sensing-to-action pipeline in which head orientation from consumer headphones selects an on-screen target and smartwatch signals detect when the user pinches;
\item design an interaction that keeps brief gesture events separate from sustained control, so that a missed or false detection cannot leave the system changing the volume on its own;
\item record and label a dataset of pinches and everyday activity, including manually corrected labels and camera-based reference labels;
\item train a causal pinch detector that runs on the laptop in real time, and evaluate it over whole recordings with event-level measures: catches, misses, latency and false activations per hour;
\item check the dataset and the stored results for reproducibility, including duplicate recordings and changing label versions;
\item identify what further studies are needed to support stronger claims, including use in AR/VR headsets.
\end{enumerate}

\section{Scope}

\paragraph{In scope.} The report covers hands-free control of laptop volume by one user, the author, using Sony WH-1000XM5 headphones for head tracking, a Samsung Galaxy Watch4 for PPG and inertial sensing, and an Apple MacBook Air (M3) running the desktop application. It describes the full system as built and evaluates the pinch-in detector on recorded data.

\paragraph{Out of scope.} Several things are deliberately left out:
\begin{itemize}
\item \textbf{Other users.} No multi-participant study has been run, so the results do not describe how the system performs for other people.
\item \textbf{A user study of the interaction.} Task time, error and workload for look--pinch--turn have not yet been measured against a conventional volume control.
\item \textbf{Pinch-out evaluation.} No matched model for pinch release was available for evaluation.
\item \textbf{AR/VR headsets.} Use in a headset is discussed as a prospect only; it was not tested.
\item \textbf{Inference on the watch.} All models run on the laptop; the watch only streams data.
\item \textbf{Other actions.} The codebase also contains a gesture-recipe engine for brightness, scrolling and media keys, and a separate drone-control experiment. Neither is evaluated in this report.
\end{itemize}
