\sect{Limitations and Reproducibility}\label{limitations-and-reproducibility}

\iffull
The main limitation is that all data come from a single participant, and we have not yet run a confirmatory usability or population study. The original hand-labelled model, \nolinkurl{pinch_in-ae0a22bf}, was reproduced by replay, but its training specification had to be reconstructed, and its original threshold-selection log and label-version hashes are missing. The newer application model was replayed using its stored run specification and historical trainer; its Model Lab weights and run files are not bundled with the replay assets. Some older cohorts cannot be checked because their UUIDs do not map to the stored recordings. Exact stream hashing misses partial overlaps, and we have not measured the reliability of the manual boundaries between annotators.

The later generations have their own limits. The motion remedy was tested with spliced motion on pinch-in only, and its parameter was chosen on the same recordings. The CNNv2 benchmark has been used repeatedly during development and holds only 20 real-use pinches from one session. The paired-detector counts rest on an archived summary whose run files were not recovered. The four-class network learns a delayed state rather than onsets, so it cannot settle whether one joint model or separate detectors is better. The current multi-gesture model was compared with the first on the first model's evaluation recordings, which had already guided earlier development.
\else
All data come from one participant, and no confirmatory or usability study has been run. The original model's training specification was reconstructed; its original threshold-selection log and label-version hashes are missing. The newer application model used its stored run specification, but its weights and run files are not bundled with the replay assets. Exact hashing misses partial overlaps, and the manual labels have not been checked by a second annotator.
\fi

\iffull
The input pipeline can be rebuilt from source, but the full original training history of \nolinkurl{pinch_in-ae0a22bf} cannot be recovered from the available artifacts. A good manifest score and a matching hash do not show the system is ready for live use. The negative recordings cover a limited range of activities, and synthetic splices cannot tell us about battery life, drift, all-day false activations or safety in real use.
\fi

\iffull
Source code, audit scripts, the export inventory and figure sources are kept as project artifacts and are available from the author on reasonable request. The original source audit refers to snapshot \nolinkurl{6709b2a}; its inventory describes the models and data stored at that point, not today's expanded collection or a newly trained release. Later model studies are separately versioned in the accompanying \nolinkurl{codex-assets} and \nolinkurl{replay-assets} packages. A complete reproduction package would also need label-version hashes tied to the original training run and its per-recording event outcomes. Sharing the physiological recordings depends on access and privacy decisions that are still to be made.

\else
Source code, audit scripts and the export inventory are available from the author on reasonable request.
\fi
